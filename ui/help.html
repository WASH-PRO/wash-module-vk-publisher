VK Publisher

Syncs the CRM Publications section (/info-messages) with a VK community feed.

VK setup

  1. Create an app or get a community access key with wall, groups, photos permissions.
  2. Set the token and community ID (numeric, without minus).
  3. Start the module in PyOrchestrator.

When a post is published

  • Status is scheduled or published
  • publishedAt time has passed
  • expiresAt has not passed (if set)
  • Category is in the filter list

VK post format

Title + body (HTML stripped). If imageUrl is set, the image is downloaded and uploaded to VK as a post attachment (up to 10 MB, JPG/PNG/WebP/GIF).

The URL must be reachable from the module container (absolute or relative to CRM API).

Module data

Published entries log: data/published_vk.json. The same CRM entry is not published twice.
